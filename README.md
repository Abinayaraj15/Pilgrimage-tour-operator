## 🚀 Quick Start / Local Preview

Since the project is built with standard web technologies, no build step or package installation is required.

### Option 1: Direct Browser Launch
Simply double-click `index.html` or `home-2.html` to open directly in any modern web browser.

### Option 2: Local HTTP Server (Python)
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
